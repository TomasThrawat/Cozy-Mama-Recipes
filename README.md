# مطبخي الدافي

تطبيق Flutter عربي دافئ للأمهات لحفظ وصفات البيت وإدارة المكونات واقتراح الوجبات.

## المزايا
- واجهة عربية RTL دافئة وغير سوداء.
- حفظ الوصفات محليًا.
- إدارة مكونات البيت.
- اقتراح الوصفات حسب المكونات المتوفرة.
- المفضلة وتفاصيل المكونات والخطوات.
- GitHub Actions يبني APK بمعمارية arm64-v8a.
